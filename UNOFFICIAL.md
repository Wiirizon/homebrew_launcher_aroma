# Unofficial community project

Simple Aroma Launcher is a separate experimental community application, not a
direct port of the original Homebrew Launcher. It is not affiliated with,
endorsed, sponsored, or approved by Nintendo or by the original Homebrew
Launcher developers. Wii U and other third-party names belong to their
respective rights holders and are used only to identify compatibility.

The native build uses public homebrew tools and does not include Nintendo's
Cafe SDK, firmware, console keys, or proprietary artwork. Original HBL code and
assets inherited by the fork are separate from the native application and are
not included in the native release packages. See THIRD_PARTY_NOTICES.md for
licenses and attribution; no ownership of those works is claimed.

Launch only homebrew you trust. This launcher executes selected applications;
it cannot make them safe or Aroma-compatible. Back up your SD card and saves
before testing experimental software. The launcher does not install system
titles, modify NAND, or provide a network service. Warranty terms are in LICENSE.
